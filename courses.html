Courses

Linear Algebra

Notes and exam papers from the M1 Artificial Intelligence class "Mathematics for Data Science" at Université Paris-Saclay. Topics include:-

  • Vectors and Matrices
  • Linear Transformations (including Kernel, Image, Rank)
  • Eigenvalues and Diagonalization
  • Orthogonality and Orthonormal Bases
  • Matrix Decompositions (SVD, Polar)
  • Norms and Conditioning
  • Tensors



Machine Intelligence and Deep Learning

Notes taken from various Machine Learning and Deep Learning courses, mainly the Pattern Recognition & Machine Intelligence (EC61211) and the Deep Learning courses offered by the EECE department, IIT Kharagpur.



Natural Language Processing

Exam papers and notes taken during Professor Animesh Mukherjee's NLP lectures (CS60075) from the CSE department, IIT Kharagpur, and Stanford's NLP course (CS224N).



Algorithms

Notes taken during Professor Debashis Sen's Algorithms course (EC31205) from the EECE department, IIT Kharagpur. Topics include:-

  • Basic Concepts and Asymptotics (Arithmetic, Fibonacci, Asymptotic Notations)
  • Divide and Conquer (Recurrences, Mergesort, Quick Sort/Select, FFT)
  • Graph Algorithms (DFS, BFS, Shortest Paths, Flows, DAGs)
  • Greedy Algorithms (MST, Set Cover, Huffman Encoding)
  • Dynamic Programming (Shortest Path, Edit Distance, Knapsack, TSP)
  • NP-Complete Problems and Approximation



Computer Architecture

Notes taken during Professor Prabir Kumar Biswas' deadly Digital Computer Architecture course (EC30202) from the EECE department, IIT Kharagpur. Topics include:-

  • Fundamentals of Computer Architecture (Instructions, Registers, Data Paths)
  • Control Unit Design (Hardwired and Microprogrammed Control)
  • Memory Organization (SRAM, DRAM, Memory Hierarchy)
  • Addressing Modes and Instruction Formats
  • ALU and Arithmetic Operations
  • Pipelining and Performance Optimization
  • Cache Memory and Virtual Memory
  • Input/Output Systems and Bus Architectures
